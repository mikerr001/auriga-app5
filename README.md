# AurigaNavi PWA

Phone-only branch of [auriga-app5](https://github.com/mikerr001/auriga-app5). `main` still has the Android app and the old website. This branch does not.

Cream paper, ink, and ember. Look, Chart, and Find. Add it to the home screen from the browser menu. There is no store build here.

```bash
npm install
npm run dev
```
